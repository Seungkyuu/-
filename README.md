# 나라장터 사전영업 지원 시스템

나라장터(G2B) 2025년 발주 데이터를 분석하여 2026년 사전 영업 일정을 수립하는 내부 웹 대시보드.

## 기술 스택

- **Frontend**: Next.js 14 (App Router) + Tailwind CSS
- **Charts**: Recharts
- **DB**: SQLite (better-sqlite3)
- **Export**: xlsx

## 시작하기

### 1. 의존성 설치

```bash
npm install
```

### 2. 환경 변수 설정

```bash
cp .env.local.example .env.local
# .env.local에 PUBLIC_DATA_API_KEY 설정 (선택)
```

### 3-A. 샘플 데이터로 즉시 시작 (API 키 불필요)

```bash
npm run dev
# 브라우저에서 http://localhost:3000 접속
# "샘플 데이터 초기화" 버튼 클릭
```

### 3-B. 실제 나라장터 API 데이터 수집

1. [공공데이터포털](https://www.data.go.kr)에서 나라장터 입찰공고정보서비스 신청
2. `.env.local`에 발급받은 API 키 설정
3. `POST /api/collect` 호출로 수집 실행

## 페이지 구성

| 경로 | 기능 |
|------|------|
| `/` | 대시보드 홈 — 업무구분별 현황, 월별 차트, 주의 기관 |
| `/projects` | 사업 목록 — 필터/정렬/엑셀 다운로드, 메모 입력 |
| `/analytics` | 발주 패턴 분석 — 히트맵, 기관 순위, 리드타임 분포 |
| `/calendar` | 2026년 영업 캘린더 — 예상 발주 일정, 알림 |

## 업무구분 필터

수집 및 분석 대상: **일반용역 / 기타 / 민간 / 기술용역** (4개)

## 핵심 비즈니스 로직

- **예상 발주월**: 2025년 입찰공고일 → 2026년 동일 월/일
- **예상 사전규격공고일**: 예상 발주일 − 평균 리드타임
- **영업 착수 알림**: 사전규격공고 예정 D-7 이내
- **준비 필요 알림**: 사전규격공고 예정 D-30 이내
